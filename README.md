# Formlyst

A visual builder for multi-step forms. Drag fields and sections, set validation rules, publish, and share a link. The form is rendered at runtime from the stored config, and responses show up in a dashboard.

Stack: React 19, TypeScript, Vite, Tailwind 4, Redux Toolkit, TanStack Query, dnd-kit, React Hook Form, Yup.

Needs a backend (forms and auth API). Copy `.env.example` to `.env` and set `VITE_API_URL` and `VITE_IMGBB_API_KEY`.

```bash
npm install
npm run dev
```
